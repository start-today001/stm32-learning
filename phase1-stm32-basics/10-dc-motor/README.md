# 6-5 PWM 驱动直流电机（调速 + 正反转）

## 硬件
- MCU: STM32F103C8T6
- 电机驱动 H 桥（L298N / TB6612 之类）：
  - **方向控制**: PA4、PA5（推挽输出 `GPIO_Mode_Out_PP`）
  - **调速**: PA2（复用推挽输出 `GPIO_Mode_AF_PP`，对应 TIM2 通道 3）
- 按键: PB1 / PB11（上拉输入 `GPIO_Mode_IPU`，按下为低电平）
- OLED: SCL = PB8、SDA = PB9（软件模拟 I2C）

## 功能
- 按 PB1 → 速度 +20；超过 100 后**直接跳到 -100**，实现反转
- 之后每按一次 +20，从 -100 递增回 100，如此循环
- OLED 第 1 行显示带符号的当前速度

## PWM 配置（PWM.c）
- 预分频 `36 - 1`：72MHz ÷ 36 = **2MHz**
- 自动重装 `100 - 1`：2MHz ÷ 100 = **20kHz**
- 引脚 PA2 配 `GPIO_Mode_AF_PP`，PA2 = TIM2_CH3 → 用 `TIM_OC3Init` / `TIM_SetCompare3`
- 速度值 = CCR（0~100，对应占空比 0%~100%）

## 为什么把 PWM 频率改成 20kHz（本项目关键点）
从 6-3 / 6-4 的 `PSC = 72-1`（1kHz）改成 `PSC = 36-1`（20kHz），原因是：

- 1kHz 落在**人耳可听范围内**，电机会随 PWM 发出"嗡嗡"的蜂鸣声
- 把开关频率提到人耳上限之上，这个声音就听不到了

**代价（要知情）**：频率越高，开关损耗越大、驱动管的开关应力越大，所以不是越高越好。

> ⚠️ 严谨说：人耳上限约 20kHz，**20kHz 是临界值**（年轻人/儿童仍可能听到）。工程上留余量一般取 **22~25kHz**，或避开结构共振频段。

## 方向控制的实现（Moter.c）
```c
Speed >= 0:  PA4 = 1, PA5 = 0,  CCR = Speed
Speed <  0:  PA4 = 0, PA5 = 1,  CCR = -Speed
```
- H 桥两个方向脚一高一低决定转向，EN 脚接 PWM 决定转速
- 反转时先取 `-Speed` 再送 CCR —— 因为 CCR 只能是非负数，**方向用普通 GPIO 表达，转速才用 PWM**

## 学习点
- **PWM 的第三种用法**：6-3 调光（改平均功率）→ 6-4 控舵机角度（脉宽即指令）→ **6-5 控电机转速 + GPIO 定方向**（PWM 只管速度，方向交给普通 IO）
- 电机 PWM 要避开音频段：这是**"代码之外"的工程约束** —— 不是功能对错，而是噪声 / EMI / 器件寿命问题
- 一个 PWM 通道 + 两个 GPIO 就能做到"正反转 + 无级调速"，这是所有电机驱动的基础模型
- `TIM_OC3Init` 对应 PA2（TIM2_CH3）：**引脚和通道的对应关系必须查数据手册**，不能凭感觉猜

## 文件
- `main.c` — 主程序（按键加速 + OLED 显示）
- `Moter.c / Moter.h` — 电机驱动（方向脚控制 + 速度→CCR，内部调用 `PWM_Init`）
- `PWM.c / PWM.h` — TIM2_CH3 PWM 输出（20kHz，PA2）
- `KEY.c / KEY.h` — 按键驱动（PB1 / PB11，上拉输入 + 20ms 消抖）
- `OLED.c / OLED.h / OLED_Font.h` — OLED 驱动（教程提供，软件 I2C 位时序 + 字库）
- `Delay.c / Delay.h` — 软件延时（复用 3-x）
