# 4-1 OLED 显示屏

## 硬件
- MCU: STM32F103C8T6
- OLED SCL: PB8（开漏输出，软件模拟 I2C 时钟线）
- OLED SDA: PB9（开漏输出，软件模拟 I2C 数据线）

## 功能
- OLED 四行显示：字符 A、字符串 HelloWorld!、十进制 12345、有符号 -66
- 第三行十六进制 0xAA55，第四行 0xAA55 的 16 位二进制

## 学习点
- 为什么 I2C 要开漏输出：总线是「线与」结构，多个设备挂在同一对线上，只有开漏 + 上拉电阻才能实现"任一设备拉低即为低"，用推挽输出会两个设备对拉短路
- 软件模拟 I2C（Bit-banging）的三个关键时序：起始条件（SCL 高电平时 SDA 下降沿）、停止条件（SCL 高电平时 SDA 上升沿）、每字节后第 9 个时钟为应答位
- 教程驱动的简化点：发送字节后第 9 个时钟只是走个形式，不读 ACK —— 这也是它比标准 I2C 好写的地方
- 驱动分层：底层位时序 → 写命令 / 写数据 → 字库查表（OLED_Font.h，一个 8x16 字符占 16 字节）→ 上层显示 API

## 已知边界
- OLED.c / OLED.h / OLED_Font.h 是江科大教程提供的驱动，不是本人编写
- 本阶段只到「会调用驱动」这一层；I2C 协议本身留到阶段二 W11 自己重写一遍（参考手册 RM0008 第 26 章 I2C）

## 文件
- `main.c` — 主程序（初始化 + 六种显示 API 各调用一次）
- `OLED.c / OLED.h / OLED_Font.h` — OLED 驱动（教程提供，软件 I2C 位时序 + 字库）
- `Delay.c / Delay.h` — 软件延时（复用 3-x）
- `stm32f10x_it.c / stm32f10x_conf.h` — 工程模板（中断向量 + 库配置）
